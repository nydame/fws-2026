Dancers Group needed a website (dancersgroup.org, 2024) whose busy homepage — alerts, a specialized hero search, event listings, curated editorial feeds, and a performances carousel — could be kept current by nonprofit staff, not a developer. I built it as a Genesis Framework child theme with Advanced Custom Fields powering each homepage component, using ACF's version-controlled local JSON workflow, an events-driven carousel, a cookie-aware alert popup, and self-hosted Google Fonts for performance. Staff now curate the entire homepage themselves — alerts, events, editorial feeds, and the performances carousel — without touching code.
